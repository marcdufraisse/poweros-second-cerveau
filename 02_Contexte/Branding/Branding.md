# Branding

## Mission

La référence visuelle : charte, palette, typographie, logos, polices, brand book. Ce que tout visuel produit doit respecter.

Ne va pas ici : les visuels produits (ils vont dans `04_Departements/Marketing/`), les supports d'un event (dans son dossier).

## Cadre

Une seule charte à la fois, dans `charte-visuelle.md` : palette par rôle, typographies, composants, ton, interdits, logo. C'est le fichier que Claude lit avant tout visuel. Les fichiers binaires (logos, polices) vivent ici, hors dépôt public. Une ligne suffit pour commencer : vos couleurs et votre police.
